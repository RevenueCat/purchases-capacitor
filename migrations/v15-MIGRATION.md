## v15 Installation Changes

This major adopts Purchases Hybrid Common 21, which is no longer published to CocoaPods trunk. Swift Package Manager (SPM) is the supported way to integrate RevenueCat's Apple dependencies.

Before upgrading, follow the [Capacitor CocoaPods-to-SPM migration guide](https://rev.cat/capacitor-spm-migration). Migrate both the core and UI packages if your app uses RevenueCat UI.
